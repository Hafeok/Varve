adr: 0247
decisions:
  - key: GeneratorInEngOnMarkdig
    statement: "The docs site is generated by eng/site, a build-tooling console project on Markdig, the one package it adds, restored locked; Markdown is read with GitHub's heading identifiers so links are judged as GitHub judges them"
  - key: SiteCarriesTheReferenceDocs
    statement: "The site carries every Markdown file directly in docs/operator, docs/problems, docs/adr, docs/decisions, docs/spec, docs/rules and docs/formats, and docs/vocabulary.md and docs/auth-providers.md, a stub marked as one for the learning track until it is written, and links to anything else of the repository as GitHub links at the commit built"
  - key: MermaidDrawnAtBuildTime
    statement: "Mermaid's own archive is fetched by exact version and the SHA-512 the register states, only its dist/mermaid.min.js is read, and it draws each diagram in Chrome with every request refused, to an SVG file of its own shown by img"
  - key: SvgsHoldNoScriptAndReachNoOrigin
    statement: "A diagram's SVG holding a script, foreignObject, iframe, embed or object, an event handler, an href, src or url other than its own fragments, an import, or an absolute URI other than a namespace name fails the build"
  - key: SiteShipsNoScript
    statement: "Every page carries the meta Content Security Policy default-src 'none'; style-src 'self'; img-src 'self'; base-uri 'none'; form-action 'none', and a built page holding a script fails the build"
  - key: LinkGateWithNamedExemptions
    statement: "Every relative link of every page the site carries names a file or directory of the repository and, to Markdown, an anchor of it; an exemption names the page, the link as written and the decision allowing it, and one matching no broken link fails"
  - key: ApiReferenceFromBaselines
    statement: "Each package's API reference is generated from its PublicAPI.Shipped.txt and PublicAPI.Unshipped.txt alone, and says while nothing is shipped that the surface shown is unshipped"
  - key: PagesFromMainByOidc
    statement: "The site is deployed to GitHub Pages from main only, through the deploy job's OIDC token, with no stored token, into the github-pages environment restricted to main; pull requests build it twice and the builds must be byte-identical"
  - key: BuildArchiveInTheRegister
    statement: "A package from outside NuGet that a build tool fetches is a BuildArchive entry in Directory.Packages.props naming its exact version, an https URL naming that version, its SHA-512 integrity, a licence on the build and test allow-list, its scope and its ADR, and the fetcher reads the pin from that entry"
