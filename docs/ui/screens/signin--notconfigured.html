This server has no sign-in for the Web UI

The server checks tokens from an issuer, and the Web UI has no client to ask it for one. Add Varve:WebUi:Auth:ClientId, Varve:WebUi:Auth:DataScope and Varve:WebUi:Auth:ManageScope to the server's configuration, and restart it.
