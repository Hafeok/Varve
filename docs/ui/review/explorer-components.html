Data explorer: proposed component cases

For review on #96 (Web UI part 2, PR (a) is #355). Every figure is one proposed contract case: when it is agreed, its markup becomes docs/ui/components/<Component>/cases/<case>.html verbatim, in the commit that builds the component, and explorer.css moves into bundle.css. QueryEditor is not here: it waits for the syntax colour tokens and its reference case from the design side. The Parts (RegimeSelect, AsOfControl, DownloadMenu) have no cases of their own; their behaviour is bUnit tests over the markup pinned here. This page in the dark theme.

Select · Atom

A labelled native <select> in Field's form. Parameters: Id, Label, Options (value, text), Selected, Help, Disabled. Generic: the regimes are RegimeSelect's (a Part), tested in bUnit.

Menu · Molecule

A disclosure button that opens a list of actions (buttons, not an ARIA menu: no roving focus to get wrong). Escape closes it and returns focus to the button. Parameters: Id, Label, Open, Items (text, note, busy). The formats are DownloadMenu's (a Part).

AskAnswer · Molecule

An ASK query's answer: the word in the metric style, with the regime and position beside it. A boolean is not a state, so no StateBadge. Parameters: Answer, Regime, Position (a PositionStamp).

ResultsTable · Organism

A SELECT answer. One column per variable, cells are TermChips, an unbound cell is named "unbound" to screen readers. The caption names the regime that answered, from the echoed Varve-Entailment; rows are never marked inferred. The foot is a live status and the actions. The client reads ahead to 5,000 rows and closes the response; the table shows them in steps of 500 and "Show 500 more" never goes back to the server (ruling D2). Parameters: Variables, Rows, Caption, Status, StatusKind, Actions.

GraphGroup · Organism

A delta or a diff grouped by graph, in graph IRI order with the default graph first. It takes each group's heading, count and body as slots (the page passes a TripleList), so it uses no organism. The summary counts what is returned to the caller and never claims a graph is hidden (ruling 2). Parameters: Summary, Groups (title, count, body).

NodeBudget · Molecule

The graph view's budget line. Over budget, it says how many nodes were left out and offers the table. Parameters: Shown, Total, Budget, TableHref.

GraphView · Organism

A bounded neighbourhood as SVG written by Razor: nodes are links in ring order (Tab), Enter follows, Space or the + control expands, arrow keys move along a ring. Edges and their labels are aria-hidden; each node's accessible name carries the relation ("dct:creator → users:alice, outgoing, inferred"). Inferred edges are dashed in edge-inferred and labelled "inferred"; a diff draws the union of both positions so unchanged nodes stay put. The component takes a laid-out model: the radial layout is a pure class tested on its own, so these cases pin rendering, not layout. Text is never scaled: the layout's bounds set the SVG's width and height one to one, and the view scrolls when it outgrows its container. Labels sit toward the neighbour end of their edge, on a surface halo, clear of every node, target and other label; a crowded sector keeps one label per predicate. Each expand target is 24×24. Parameters: Title, Nodes (x, y, term, kind, type, diff, expandable, expanded, accessible name, href), Edges (from, to, label, kind), Labels (x, y), Bounds, Budget (a NodeBudget).

ValidationReport · Organism

One binding's report, read from its report graph at one position. Grouped by shape or by focus node (the Tabs molecule). Severity is a StateBadge with its word (violation critical, warning warn, info neutral; the mapping is Tones', ADR 0206 point 5). A path is written in SPARQL path syntax. A 503 validation-behind and the withheld report are the page's: the first as ProblemPanel, the second as the not-returned case. Parameters: Conforms, Count, Position, Grouping, Groups (title, count, rows).

Triple · Molecule (changed)

The existing inferred case's note becomes "inferred" (ruling 8); from-ontology is new (ruling D4): the same dashed treatment, since neither is asserted in this graph, and the word tells them apart. Shown in a table here; the cases are within: tbody as now.
