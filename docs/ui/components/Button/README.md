# Button

Quiet by default. **Primary** (`accent` fill) at most once per view, for the act the view exists for. **Danger** (outlined in `critical`) for an act that stops service; **danger-solid** only as the confirming button inside its dialog.

- **Consumer provides:** a verb-first label in sentence case that names the effect ("Close dataset", "Take checkpoint", "Return to head").
- A disabled act explains itself in a caption beside it ("Only the writer takes checkpoints"); a button never disables silently.
- `vw-button--small` inside dense rows and stamps.
