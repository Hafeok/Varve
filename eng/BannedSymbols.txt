// --- IRIs -------------------------------------------------------------------
// System.Uri implements RFC 3986 with its own normalisation, and is not RFC 3987.
// It lowercases schemes and hosts, resolves dot segments eagerly, and rejects
// IRIs that RDF requires us to round-trip byte for byte. Use Varve.Iri.
// ADR 0004. Scope note: this ban is repository-wide today because nothing
// consumes System.Uri yet. It must be narrowed before layer 5 exists — a server
// speaks HTTP and will need it. See ADR 0004, "Consequences".
T:System.Uri; Use Varve.Iri. System.Uri is RFC 3986 with its own normalisation and cannot round-trip an IRI. ADR 0004.

// --- constraint 2: no runtime code generation -------------------------------
// Reflection.Emit does not exist under Native AOT and is unavailable in WASM.
// Where code generation is needed, it is a source generator. ADR 0004.
N:System.Reflection.Emit; Native AOT and WASM have no Reflection.Emit. Use a source generator. ADR 0004.

// --- constraint 2: no dynamic -----------------------------------------------
// ADR 0064. The brief bans dynamic in shipped code. This bans the runtime
// binder's types where source names them. It does NOT catch the dynamic
// keyword itself: the compiler emits the binder calls, and BannedApiAnalyzers
// sees only symbols the source references (verified against 5.6.0 by a scratch
// build during session 2 of #43, and reported there). Until a rule covers the
// keyword, review is the check.
N:Microsoft.CSharp.RuntimeBinder; No dynamic: the runtime binder is reflection, and Native AOT cannot carry it. ADR 0064.
