// --- IRIs -------------------------------------------------------------------
// System.Uri implements RFC 3986 with its own normalisation, and is not RFC 3987.
// It lowercases schemes and hosts, resolves dot segments eagerly, and rejects
// IRIs that RDF requires us to round-trip byte for byte. Use Varve.Iri.
// ADR 0004. Scope note: this ban is repository-wide today because nothing
// consumes System.Uri yet. It must be narrowed before layer 5 exists — a server
// speaks HTTP and will need it. See ADR 0004, "Consequences".
T:System.Uri; Use Varve.Iri. System.Uri is RFC 3986 with its own normalisation and cannot round-trip an IRI. ADR 0004.

// --- constraint 2: no runtime code generation -------------------------------
// Reflection.Emit does not exist under Native AOT and is unavailable in WASM.
// Where code generation is needed, it is a source generator. ADR 0004.
N:System.Reflection.Emit; Native AOT and WASM have no Reflection.Emit. Use a source generator. ADR 0004.

// --- constraint 2: no reflection over names ---------------------------------
// Each of these defeats the trimmer: the referenced type is named in a string,
// so the trimmer cannot see the reference and removes the type. They are the
// APIs behind IL2026/IL2057/IL2072, banned outright rather than suppressed.
M:System.Type.GetType(System.String); Type names in strings defeat trimming. ADR 0004.
M:System.Type.GetType(System.String,System.Boolean); Type names in strings defeat trimming. ADR 0004.
M:System.Type.GetType(System.String,System.Boolean,System.Boolean); Type names in strings defeat trimming. ADR 0004.
M:System.Activator.CreateInstance(System.Type); Use a constructor or a factory delegate. Reflective activation defeats trimming. ADR 0004.
M:System.Activator.CreateInstance(System.Type,System.Object[]); Use a constructor or a factory delegate. Reflective activation defeats trimming. ADR 0004.
M:System.Activator.CreateInstance(System.String,System.String); Use a constructor or a factory delegate. Reflective activation defeats trimming. ADR 0004.
M:System.Reflection.Assembly.Load(System.String); Dynamic assembly loading is unavailable under Native AOT. ADR 0004.
M:System.Reflection.Assembly.Load(System.Byte[]); Dynamic assembly loading is unavailable under Native AOT. ADR 0004.
M:System.Reflection.Assembly.LoadFrom(System.String); Dynamic assembly loading is unavailable under Native AOT. ADR 0004.
M:System.Reflection.Assembly.LoadFile(System.String); Dynamic assembly loading is unavailable under Native AOT. ADR 0004.
