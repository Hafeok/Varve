// Ambient time and ambient randomness. Applies to packable projects that set
// VarveDeterministic; see Directory.Build.targets.
//
// ADR 0011: §10's determinism property compares the log/ directories of two
// machines byte for byte, with an injected clock. Anything that reads the
// machine's clock or a random source inside Varve.Store would make that
// comparison depend on when and where it ran. ADR 0018's fourth impossibility
// says the same of the storage contract, and ADR 0040 puts the memory backend
// in Varve.Store, under this list.
//
// The clock is DatasetOptions.Clock, a TimeProvider the caller supplies. It is
// required, so there is no default for this list to have to exempt.

// --- ambient clock ------------------------------------------------------------
P:System.DateTime.Now; Ambient clock. Use the injected TimeProvider (DatasetOptions.Clock). ADR 0011.
P:System.DateTime.UtcNow; Ambient clock. Use the injected TimeProvider (DatasetOptions.Clock). ADR 0011.
P:System.DateTime.Today; Ambient clock. Use the injected TimeProvider (DatasetOptions.Clock). ADR 0011.
P:System.DateTimeOffset.Now; Ambient clock. Use the injected TimeProvider (DatasetOptions.Clock). ADR 0011.
P:System.DateTimeOffset.UtcNow; Ambient clock. Use the injected TimeProvider (DatasetOptions.Clock). ADR 0011.
P:System.TimeProvider.System; The system clock is the caller's choice, not the store's. Take a TimeProvider. ADR 0011.
T:System.Diagnostics.Stopwatch; Ambient clock. Time through the injected TimeProvider. ADR 0011.
P:System.Environment.TickCount; Ambient clock. Use the injected TimeProvider. ADR 0011.
P:System.Environment.TickCount64; Ambient clock. Use the injected TimeProvider. ADR 0011.

// --- ambient randomness -------------------------------------------------------
T:System.Random; Ambient randomness. Nothing in the log may depend on it (spec §10, determinism). ADR 0011.
T:System.Security.Cryptography.RandomNumberGenerator; Ambient randomness. Nothing in the log may depend on it (spec §10, determinism). ADR 0011.
M:System.Guid.NewGuid; Ambient randomness. Ids are counters allocated by the sequencer (ADR 0012). ADR 0011.
