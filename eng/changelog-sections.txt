# One line per section, oldest first: "<commit-ish> <title>". The commit named

# next one starts, and the last runs to HEAD.

# main, so the boundary between them exists only in the intent — and a
# derivation that silently merges two milestones into one is worse than five
# lines naming where each began.
#
# Once a v* tag exists, tags become the sections and this file applies only to
# what is unreleased.
